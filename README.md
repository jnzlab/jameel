# 🚀 Jameel Ahmad | Portfolio & Blog

Welcome to the source code of my personal website! This project serves as my digital home where I showcase my professional work, open-source contributions, and share my journey through technical blog posts.

Live Site: **[jnzlab.io](https://jnzlab.io)**

## 👤 About This Project

This site is built to represent my identity as a **Full Stack Developer**. It’s not just a portfolio; it’s a living document of my experiences in the JavaScript/TypeScript ecosystem — from freelance client work at **Innovorus** to AI-powered products, e-commerce storefronts, and open-source developer tooling.

### Key Features:

* **Portfolio:** A showcase of my work, including AI-powered candidate screening ([LucidHire](https://lucidhire.io)), e-commerce ([Pouch Parlour](https://pouchparlour.com)), a CLI tool ([easy-ytdlp](https://www.npmjs.com/package/@jnzlab/easy-ytdlp)), and live-status microsites ([Hafiz Chaska Point](https://hafiz-chaska-point.vercel.app)).
* **Blog:** Insights on Next.js, TypeScript, Fedora Linux, and lessons from shipping production software.
* **Performance:** Built with Astro for lightning-fast loading and optimal SEO.

## 🛠️ Tech Stack

* **Framework:** [Astro](https://astro.build/) (AstroPaper Theme)
* **Styling:** Tailwind CSS
* **Search:** Pagefind
* **Deployment:** Vercel
* **Domain Management:** AWS Route 53

## 📖 Content Strategy

I use the blog section to document:

1. **Technical Tutorials:** Solving specific bugs in Next.js or configuring Fedora.
2. **Project Deep-Dives:** Explaining the "why" behind my architectural choices (like hybrid vector search or real-time streaming architectures).
3. **Career Journey:** Sharing my path as a freelance full-stack developer and open-source contributor.

## 🏃 Local Development

If you'd like to run this project locally to see how I've structured my Astro components:

1. **Clone the repository:**
```bash
git clone https://github.com/jnzlab/jameel.git

```


2. **Install dependencies:**
```bash
pnpm install

```


3. **Start the development server:**
```bash
pnpm dev

```
